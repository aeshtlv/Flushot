# Идеи развития

Что можно добавить дальше, зачем это нужно и насколько сложно. Это не обещания: список существует,
чтобы не изобретать заново то, что уже обдумано, и чтобы было видно, что осталось за рамками.

## Что можно добавить

| Идея | Зачем | Сложность |
|---|---|---|
| **Автоскрытие персональных данных** | найти на снимке почту, телефон, номер карты и паспорта и замазать их самому — до того, как снимок уйдёт в чат | средняя |
| **Привязка выделения к границам окон** | рамка сама цепляется за края окна под курсором: ровный снимок окна без подгонки мышью | средняя |
| **Повторить прошлую область** | отдельная клавиша снимает тот же прямоугольник, что и в прошлый раз — для повторяющихся снимков виджета или графика | низкая |
| **Закрепить на экране** | снимок остаётся поверх всех окон, пока его не закроют: удобно сравнивать с тем, что на экране | средняя |
| **Копировать как файл** | в буфере не только картинка, но и файл (`CF_HDROP`), чтобы вставить его в Проводник или чат как вложение | низкая |
| **Пипетка и лупа с сеткой** | точный пиксель и цвет под курсором (`#RRGGBB`) — пригодится при выделении в один пиксель | низкая |
| **История снимков в трее** | вернуться к снимку, который уже закрыли | средняя |
| **Съёмка активного окна по клавише** | один клик вместо точного выделения | низкая |
| Задержка съёмки (3/5/10 с) | поймать открытые меню, подсказки, hover-состояния | низкая |
| Пиксельные пресеты холста (1920×1080, 1200×630, 1080×1350) | обложки для соцсетей | низкая |
| Загрузка по ссылке (свой сервер/S3) с копированием URL | делиться снимком, а не файлом | высокая |
| Распознавание текста на других языках | движок Windows читает только установленные языки; для остальных нужен Tesseract или облако | высокая |

## Что уже сделано

Реализовано в 2.2.8: в трее настоящий логотип в двух раскрасках, распознавание читает снимок трижды.
Реализовано в 2.2.7: единый логотип — один рисунок из `logo/` во всех местах, где он появляется.
Реализовано в 2.2.6: правка распознанного текста прямо в панели.
Реализовано в 1.7.0: автозапуск с Windows, правка сохранённого текста, нумерация шагов.
Реализовано раньше: рамка и скругление в настройках (1.5.0, 1.6.0), редактор пометок (1.6.0), WebP (1.6.0), перенос текста (1.6.1).
