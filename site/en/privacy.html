Privacy

In short: the program sends nothing about you, and this site counts visits only with your consent. The details follow, without “we may share data with partners” wording.

Last updated 22 November 2026.

The Flushot program

Screenshots, the frame around them, annotations and text recognition all happen on your computer. Neither the picture, nor its contents, nor file names are sent anywhere — the program has no account, no analytics and no install identifier.

Once a day the program asks GitHub whether a new version exists and, if it does, downloads it in the background. There are no other requests, and this one can be switched off in settings under “Updates”, after which the program does not use the network at all. The owner of api.github.com sees your computer’s IP address and the program version — as with any request to any site.

Downloading a file from GitHub goes through github.com and is counted on the release page. That counter measures downloads, not installations, and it is not tied to any particular person.

Pictures uploaded as a link

One of the three shortcuts, “With a link”, sends the picture to a server and puts a link to it on the clipboard. That is the only case in which a picture leaves your computer. The other two keys work locally only, and nobody has to press this one.

What is stored. The finished picture as a whole — the same file you would get by saving it, with the frame, the shadow and the annotations already baked in. Nothing else: no file name, no name of yours, no account. The name on the server is sixteen random characters, so the link is tied neither to you nor to any other picture.

How long it is kept. Exactly one hour from the upload. After that the picture is deleted from the server automatically — not “may be deleted”, but deleted: a separate task runs every minute and does it. The link then shows a “Link expired” page. Someone who already has the picture open in a browser will see it until the hour is up; a copy saved beforehand cannot, of course, be recalled.

Who can see it. Anyone holding the link: there is no password on it. The link is hard to guess but public — do not post it anywhere the wrong people will see it. Search engines do not index it, and the server forbids indexing outright with an X-Robots-Tag header.

Logs. The server records the upload itself: time, size and IP address, as every web server does. The logs are kept for ten days. The contents of the picture never reach them.

If a picture was uploaded without your consent. The link can be cancelled early: DELETE https://flushot.ink/api/shot/<the link without its extension> deletes the file immediately. The same address is where to write if something went wrong.

This site

The site is a static page. It has no forms, no sign-up and no comments, so there is no user data that could be stored about you.

Visit statistics. To know how many people visit the site and where they come from, Yandex.Metrika is used. It starts only after “Accept” is pressed in the cookie notice. If you press “Decline”, the Metrika script is not loaded at all: no cookie and no request to Yandex servers.

With statistics enabled, Yandex receives: the page address, your IP address and the region derived from it, browser and operating system, window size, the address of the page you arrived from, and information about scrolling and clicks on this page (the click map). Metrika cookies are kept for up to one year. We see aggregated reports only: how many visits there were, which search engines sent them, which buttons were pressed. We do not link this data to you and pass it to nobody except Yandex, which collects it in the first place.

How Metrika handles data is described in Yandex’s own documents: the terms of service and the privacy policy.

Server logs

The server that hosts the page records requests in a plain nginx log: IP address, date, page address and browser name. This is what makes it possible to find faults and keep junk traffic out. The logs are kept for ten days and then deleted automatically.

How to opt out

The button below erases the stored answer, so the notice will ask again on your next visit — and you can answer “Decline”. If statistics were already enabled, declining stops the script from loading in future; cookies Metrika already set are removed with your browser’s own tools.

What changed

This page appeared on 22 November 2026, together with the visit counter. Before it, the site set no cookies and loaded no third-party scripts — and before the counter existed, that was visible in the page source.
