How it works

Two steps, one paste

  1. 1 Press your key. By default it is Ctrl+Shift+S, but you can change it to any key. The screen dims.
  2. 2 Release the mouse. The size is shown next to the frame and updates as you drag. By the moment you let go, the screenshot is already in the clipboard — all that is left is Ctrl+V wherever you are pasting it.

What happens to a screenshot before and after Flushot.

The usual way

  • The screenshot is cropped at the window edge, with a white strip along the bottom
  • The shadow and corners do not match the design, so you fix them by hand
  • The underline is “almost horizontal” — and it shows
  • The file screenshot.png overwrote the previous one

With Flushot

  • With Shift, the line locks to exactly 0°, 45° or 90°
  • The name carries the date: screenshot_2026-10-21_10-34-11.png

Hotkeys

The keys are yours, not ours

The text above shows the default values. They really are defaults: both keys can be changed in the settings to whatever suits you. Below is a working demonstration: press “Change” and type a shortcut.

How it works

  • Press “Change” and simply type the shortcut — it records itself as you go, with no dropdown lists.
  • If another program already owns that shortcut, Flushot says so and offers another.
  • You cannot assign the same key twice: Windows gives a shortcut to one action only.
  • Each key has a “Reset” that restores the default.
  • Punctuation marks work too: Ctrl+=, Ctrl+-.
  • Esc cannot be assigned — Windows does not give it to programs.
  • Win+Shift+S belongs to the Windows Snipping Tool — no application can take that shortcut while the Snipping Tool is installed. The settings say so and offer either to uninstall the Snipping Tool or to type another shortcut.

Questions

Common questions

The screenshot went to the clipboard by itself. Is that how it should be?

Yes, that is the main mode. Releasing the mouse button copies the finished card to the clipboard and closes the selection overlay, so you can paste right away: Ctrl+V in a chat, an email or a document. There is no need to press Ctrl+C.

Annotations and saving are still there: holding Shift while you release the button opens the screenshot in the editor, and the “After selection → Open” switch in the settings does the same. An accidental click, or a region smaller than 24 × 24 px, is not copied — the clipboard stays as it was.

Windows says the program is unsafe. Is that dangerous?

No. The warning appears because there is no digital signature, not because of the content. A signature is a paid certificate, and one is not bought for a free program. Press “More info” → “Run anyway”.

Where are screenshots saved?

By default into Pictures\Flushot. The folder can be changed in the settings, which also has a button that opens it in File Explorer. The file name is the date and time, so nothing is overwritten.

The file is written even when the screenshot has gone to the clipboard: writing happens after the copy and does not hold the paste up.

Can the hotkeys be changed?

Yes, both. If another program already owns that shortcut, Flushot says so. You cannot assign the same key twice: Windows gives a shortcut to one action only.

And Win+Shift+S cannot be assigned by us or by anyone else: while the Windows Snipping Tool is installed, that shortcut belongs to it. The settings name the owner and offer two ways out: uninstall the Snipping Tool, or type another shortcut.

There are no ready-made buttons with suggested shortcuts in the settings: you assign the shortcut yourself, by typing it. Someone else’s suggestions only got in the way there.

How do I get the text out of a screenshot?

The “Text” button turns on fragment selection: outline the part you need on the screenshot and the recognised text appears alongside, ready to copy with one button. Pressing the button without outlining anything reads the whole screenshot. This uses the built-in Windows engine, the same one as the Snipping Tool: nothing is downloaded, no internet is needed, and the screenshot never leaves the computer. A card of 880 × 1200 with twenty lines takes about 1.1 s to read after the first launch — three reads instead of one cost about 0.6 s and pay for themselves in fewer mistakes.

The text in the panel can be edited: click a word, correct it, “Copy corrected” — the clipboard receives the corrected text, with no round trip through Notepad. The “edited” marker and the “Revert” button show how the text differs from what the engine read.

A Windows engine handles one language only, so every installed engine reads at once and the results are merged line by line: each engine is right about exactly its own alphabet, and there is no best engine for a mixed screenshot. On top of that, each screenshot is read three times — at the chosen scaling, at two thirds of it, and once more in black and white — and a disputed word is settled by a vote. On a set of 20 lines of real text at four font sizes this gave 3.22 % wrong characters against 3.50 % for a single read.

This is not OCR for scans: with small type and coloured text over a picture the engine makes mistakes. Where every read agrees on something wrong (at 11 px both engines read the same word the same wrong way), there is nothing to merge — and that is exactly the case manual editing is for.

Does it work with two monitors?

Yes. The selection spans the combined area of all monitors, even when they are different sizes and stacked one above the other. The screenshot is assembled from both at their native resolution. The separate “full screen” key captures the primary monitor.

Is an internet connection needed?

No. The program makes no network requests at all: no update checks, no telemetry, no account sign-in. Download it once and it works offline for as long as you like.

What about picture quality?

The screenshot is taken in the monitor’s physical pixels, so at 125 % or 150 % scaling it is not blurry. PNG is saved losslessly. If you need a lighter file, JPEG with adjustable quality and WebP are available.

Is there an English version?

No, the interface is Russian only. That is one of the honest limits: the translation has not been made yet.

Can I delete one annotation out of several?

Ctrl+Z undoes the last action. A single numbered step cannot be removed from the middle — the numbering is recalculated automatically, and removing one selectively would break it.

Is it really free?

Yes. No ads, no subscriptions, no cut-down versions and no sign-up.

Limitations

What is still missing

Better to find out here than after the download.

  • Russian only. There is no English translation of the interface.
  • The files are not signed. SmartScreen warns on first launch. The source code is open on GitHub, so you can read it before running anything.
  • Annotations are baked in when you save. Before that you can move them; afterwards you cannot.
  • Blur in the preview is coarser than in the finished file.
  • A single annotation cannot be deleted — only the last action.
  • “Full screen” means the primary monitor, not all monitors in one picture.
  • Esc cannot be assigned: Windows does not give it to programs.
  • Windows 10 and 11 only. There are no macOS or Linux versions.
