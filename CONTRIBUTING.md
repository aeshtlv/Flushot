# Участие в разработке

Спасибо, что заглянули. Ниже — то, что нужно знать, чтобы правка не сломала поведение, которое
проверяется тестами.

## Требования

**Windows 10/11 x64**, **Node.js 20.19+ или 22.12+**, npm. Приложение использует Electron,
`sharp` и встроенный движок распознавания Windows, поэтому собрать и прогнать его целиком можно
только на Windows.

```bash
npm install
npm run dev
```

## Перед pull request

```bash
npm run typecheck    # обязателен: tsc для main и renderer
npm test             # обязателен: 351 тест
```

Оба шага прогоняет CI (`.github/workflows/ci.yml`) на Windows. Если правка касается интерфейса,
полезно дополнительно прогнать `node scripts/make-ui-shots.cjs` и `node scripts/verify-ui-shots.cjs`:
они снимают настоящую сборку окна в headless-браузере и проверяют геометрию по пикселям.

## Правила, которые здесь не обсуждаются

Это не вкусовщина — каждое правило появилось после конкретной ошибки, и тесты их охраняют:

- **Качество не перекодируется.** Снимок не масштабируется, превью не растягивается, PNG не
  проходит через повторное кодирование. `tests/quality.test.ts` сравнивает результат с исходным
  кропом побайтово (`maxDiff = 0`).
- **Геометрия — чистая функция.** Вся математика размеров, рамки, скругления и позиционирования
  живёт в `src/main/imaging/layout.ts` и `src/shared/*` и тестируется без GUI. Логику, которую можно
  посчитать числом, не прячут в компонент.
- **Логотип не рисуется вручную.** Единственный исходник — `logo/logo.svg`; `src/shared/logo.ts`
  держит его копию для приложения, и `tests/logo.test.ts` падает, если копия разошлась с файлом.
  Значок в трее — тот же рисунок, а не упрощённая переделка: меняться может только раскраска.
- **Измерения вместо обещаний.** Если в README написано «3,22 % ошибок» или «237 мс», за этим стоит
  замер, а не оценка. Не подставляйте числа без прогона.
- **Ошибка не роняет окно.** Все IPC-обработчики возвращают `{ ok, message }` через `guard()`;
  новый обработчик без него — регрессия.

## Стиль

- TypeScript, без `any` в публичных подписях; комментарии объясняют **почему**, а не что.
- Русский язык в интерфейсе и документации, английский — в именах кода.
- Сообщения коммитов: короткая строка в повелительном наклонении, затем — почему это понадобилось.

## Что проверять руками

Автотесты не покрывают то, что видно только на живой системе: захват с двух мониторов с разным
масштабом, поведение оверлея при 150 %, реальное распознавание на вашем шрифте. Для этого есть
`npm run self-test` — он запускает приложение без пользователя и печатает JSON-отчёт с замерами.
Описание полей — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#самопроверка).
