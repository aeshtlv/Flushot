1. TELEGRAM — ОСНОВНОЙ ПОСТ
   Картинка: 01-квадрат-1080.png
───────────────────────────────────────────────────────────────────────────

Скриншот за две секунды, и сразу выглядит нормально

Каждый раз одно и то же: сделал снимок экрана, вставил в чат — и он либо
обрезан, либо растянут, либо на нём видно пол-рабочего стола. Приходится
открывать редактор, обрезать, добавлять рамку. На один скриншот уходит
минута, а нужен он был десять секунд назад.

Flushot делает это за один жест:

1. Ctrl + Shift + S — экран темнеет, выделяешь область.
2. Отпускаешь мышь — снимок уже в рамке, с тенью и скруглёнными углами.
3. Ctrl + C — и он в буфере. Или Ctrl + S — файл в папке.

Клавишу при этом выбираешь сам. Ctrl + Shift + S — только значение по
умолчанию; в настройках ставится любая, хоть Print Screen или F1. Если
сочетание занято другой программой, Flushot так и скажет и предложит другое.

Что внутри:

• Ровная линия. Нужна, чтобы подчеркнуть строку в договоре или в таблице.
  С зажатым Shift линия прилипает к 0, 45 или 90 градусам — подчёркивание
  получается горизонтальным, а не «почти горизонтальным».
• Снимок всего экрана одной клавишей — без рисования рамки. Обе горячие
  клавиши, для области и для всего экрана, переназначаются в настройках.
• Пометки: стрелка, прямоугольник, карандаш, текст, нумерованные шаги,
  размытие. Ctrl + Z отменяет последнее.
• Сохранение в папку сразу, с датой в имени: screenshot_2026-10-18_14-30-25.png
  Ничего не перезапишется и не потеряется.
• PNG без потерь, а если нужен файл полегче — JPEG и WebP.
• Много мониторов и масштаб экрана 125 % / 150 % — рамка не уезжает.

Бесплатно. Без рекламы, без подписок, без интернета — программа вообще не
ходит в сеть. Windows 10 и 11, распаковал и запустил.

   Картинка: 03-широкий-1920x1080.png

Скриншоты, которые не стыдно отправить

Знакомая ситуация: нужно показать коллеге ошибку в программе. Делаешь
снимок экрана, вставляешь в сообщение — а там половина рабочего стола,
кривая обрезка и текст, который невозможно прочитать.

Flushot — маленькая программа для Windows, которая убирает эту возню.

Как работает:
— Нажимаете свою клавишу (по умолчанию Ctrl + Shift + S), экран темнеет,
  выделяете мышью область.
— Отпускаете кнопку — снимок сразу в аккуратной рамке с тенью.
— Ctrl + C — копия в буфере. Ctrl + S — файл в папке, с датой в имени.

Для чего это удобно:
— Подчеркнуть строку в договоре или в таблице. Инструмент «Линия» с зажатым
  Shift даёт строго горизонтальную черту, а не «на глазок».
— Снять весь экран одной клавишей, когда рамку рисовать некогда.
— Назначить любые горячие клавиши. По умолчанию Ctrl + Shift + S и
  Ctrl + Shift + 3, но ставятся и Print Screen, и F1 — что удобно именно вам.
— Обвести ошибку, поставить стрелку, закрыть номером шага, замазать
  персональные данные размытием.
— Сохранять сразу в папку, чтобы не искать снимок по всему диску.

Программа бесплатная. Рекламы нет, подписок нет, в интернет она не выходит.
Работает на Windows 10 и 11, с двумя мониторами и с масштабом экрана 125 %
и 150 %.

Скачать: [ссылка]

Если Windows покажет синее предупреждение при первом запуске — это обычное
дело для бесплатных программ без платной цифровой подписи. Нажать
«Подробнее» → «Выполнить всё равно».

7. REDDIT / ЗАРУБЕЖНЫЙ ФОРУМ — ENGLISH

I built a small screenshot tool for Windows and I'm sharing it for free

The thing that annoyed me: taking a screenshot, pasting it into a chat, and
getting a stretched, badly cropped picture with half my desktop on it. Then
opening an editor to fix it. One minute of work for something that should
take two seconds.

Flushot: press Ctrl + Shift + S, drag a region, release. The capture appears
with a frame, a soft shadow and rounded corners. Ctrl + C to copy, Ctrl + S
to save.

Those keys are just defaults — both shortcuts are rebindable in the settings,
so you can put capture on Print Screen, F1, or whatever your hands expect.

What else it does:
- A straight line tool for underlining. Hold Shift and it snaps to 0, 45 or
  90 degrees, so the underline is actually horizontal.
- Ctrl + Shift + 3 captures the whole screen in one keystroke. Both shortcuts
  can be changed to anything you like.
- Arrows, rectangles, freehand, text, numbered steps, blur for redacting.
- Saves straight to a folder with a timestamped name, so nothing is
  overwritten. PNG by default, JPEG and WebP if you want smaller files.
- Multi-monitor and 125 % / 150 % display scaling handled properly.

It's free, no ads, no account, and it makes no network requests at all — you
can run it offline forever.

Two honest caveats: the interface is in Russian only, and the build is not
code-signed, so Windows SmartScreen will warn on first launch (More info →
Run anyway).

10. ЧЕГО НЕ ПИСАТЬ
───────────────────────────────────────────────────────────────────────────

Это важно, если не хотите получить в ответ «а обещали другое».

Не пишите «заменяет Photoshop», «как на macOS» (речь о тени, а не о системе),
«лучший скриншотер», «работает везде» — программа только для Windows.

Не пишите про OCR, распознавание текста, загрузку в облако, историю снимков
и мобильную версию. Этого в Flushot нет.

Не обещайте «без предупреждений Windows» — предупреждение будет, пока файл
не подписан сертификатом. Лучше предупредить об этом заранее, как в постах
выше: люди спокойно относятся к честному «SmartScreen ругается, это нормально».

Не пишите «русский и английский». Интерфейс только русский.

Не приписывайте себе чужое: если делаете пост про «сделал сам», так и
пишите. Программа собрана на Electron — это нормально, но не нужно
называть её «нативной».

Честно о мелочах, если спросят в комментариях:
— «Весь экран» — это основной монитор, а не все мониторы одной картинкой.
— Пометки вшиваются в файл при сохранении или копировании, а не раньше.
— Размытие в предпросмотре грубее, чем в готовом файле.
— Отменить отдельный нумерованный шаг нельзя, только последнее действие.
— Клавишу Escape назначить нельзя: Windows не отдаёт её программам.
— Две одинаковые клавиши поставить нельзя: Windows отдаёт сочетание только
  одному действию. Flushot скажет об этом сразу, а не молча проигнорирует.

   которой как раз нужны утилиты.

Дальше, если захочется:
— Пикабу, раздел «Личное» или «Софт». Формат «сделал для себя» работает
  лучше рекламного.
— vc.ru — нужен пост с историей: зачем сделал, что было сложно. Голые
  скриншоты там не читают.
— Reddit: r/Windows10, r/software, r/screenshots. Только с английским
  текстом из раздела 7 и обязательно с пометкой про русский интерфейс —
  иначе в комментариях будет неприятно.
— Habr — там нужна техническая статья, а не реклама. Проще написать «как
  я делал захват экрана с учётом DPI и двух мониторов» и упомянуть
  программу в конце.

Правило, которое экономит нервы: не публикуйте один и тот же текст в пять
мест за один час. Перепишите первые две строки — их читают, остальное нет.
