# Flushot

Программа для скриншотов на Windows. Выделяете область — получаете готовый снимок в аккуратной рамке
с мягкой тенью и скруглёнными углами, без потери качества. Windows 10 и 11, x64.

## Возможности

- **Снимок любой области.** Результат — выделение плюс рамка, поэтому размер произвольный:
  от 300×270 до 3840×2160. Изображение не масштабируется, пиксели копируются один к одному.
- **Оформление.** Рамка 0–200 px с четырёх сторон, цвет на выбор, скругление углов, мягкая тень
  с настройкой интенсивности и радиуса — или чистый снимок без полей.
- **Пометки.** Стрелка, линия, прямоугольник, карандаш, текст с переносом по словам, нумерованные
  шаги, размытие и пикселизация приватных участков. Готовые пометки можно перемещать.
- **Распознавание текста.** Кнопка «Текст» читает снимок или обведённый фрагмент встроенным движком
  Windows: офлайн, без загрузок, изображение не покидает компьютер. Текст правится в панели.
- **Копирование и сохранение.** `Ctrl+C` — сразу в буфер, в том числе во время выделения.
  `Ctrl+S` — в файл. Автосохранение в папку, имена вида `screenshot_2026-10-17_14-30-25.png`,
  форматы PNG, JPEG и WebP.
- **Мониторы и DPI.** Выделение тянется через границу экранов, результат собирается в исходном
  разрешении. Корректно при масштабе Windows 100, 125, 150 и 200 %.
- **Трей и горячие клавиши.** Отдельные клавиши для области и для всего экрана, автозапуск с Windows,
  значок в трее следует теме панели задач.

## Установка

Готовые сборки — в [Releases](../../releases/latest). Программа внутри одинаковая, отличается способ
установки.

| Файл | Описание |
|---|---|
| **[Flushot-2.2.8-win64.zip](../../releases/latest/download/Flushot-2.2.8-win64.zip)** | 161 МБ. Распаковать в любую папку и запустить `Flushot.exe`. Временная папка Windows не требуется — рекомендуемый вариант |
| [Flushot-2.2.8-installer.zip](../../releases/latest/download/Flushot-2.2.8-installer.zip) | 113 МБ. Установщик NSIS: ярлыки в меню «Пуск», выбор папки, деинсталлятор |
| [Flushot-2.2.8-portable.zip](../../releases/latest/download/Flushot-2.2.8-portable.zip) | 113 МБ. Portable-версия одним файлом, без установки |

Сборки не подписаны сертификатом разработчика, поэтому при первом запуске SmartScreen показывает
предупреждение: **«Подробнее» → «Выполнить всё равно»**. Это стандартное поведение для неподписанного
исполняемого файла.

Страница программы с описанием и кнопками скачивания: **https://flushot.ink**

## Сборка из исходников

Требования: **Windows 10/11 x64**, **Node.js 20.19+ или 22.12+**, npm.

```bash
git clone https://github.com/aeshtlv/Flushot.git
cd Flushot
npm install
npm run dev
```

При первом запуске открывается окно настроек, приложение остаётся в трее.

```bash
npm run typecheck    # tsc для main и renderer
npm test             # 351 тест в 23 файлах
npm run build        # production-сборка в out/
npm run dist         # установщик и portable в release/
npm run self-test    # сквозная проверка на живой системе
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+S` | начать выделение области |
| `Ctrl+Shift+3` | снимок всего экрана |
| `Enter` | подтвердить выделение |
| `Ctrl+C` | скопировать в буфер без предпросмотра |
| `Ctrl+S` | сохранить результат |
| `Ctrl+Z` | отменить последнюю пометку |
| `Esc` | сбросить выделение или закрыть оверлей |
| `Shift` при рисовании линии | прилипание к 0°, 45° или 90° |

Обе клавиши запуска переназначаются в настройках, в том числе на одиночную клавишу без модификаторов.
В поле распознанного текста клавиши работают как в обычном текстовом поле; `Ctrl+S` при этом
по-прежнему сохраняет снимок.

## Ограничения

- Захват выполняется средствами Electron, поэтому защищённый контент (DRM, часть игр в exclusive
  fullscreen) может выйти чёрным. Это ограничение операционной системы.
- Снимок делается в момент нажатия клавиши: оверлей показывает замороженный кадр.
- Сборка под macOS и Linux не настроена.
- Распознавание читает только языки, установленные в Windows, и ошибается на мелком шрифте и цветном
  тексте поверх изображения. Средняя ошибка на тестовом наборе — 3,22 %.
- `Win+Shift+S` нельзя назначить, пока установлены «Ножницы»: сочетание закреплено за ними
  на уровне системы.

## Структура проекта

```
src/main/        процесс Electron: захват, сборка карточки, экспорт, распознавание, настройки, трей
src/renderer/    интерфейс: оверлей выделения, панель пометок, окно настроек
src/shared/      общие типы, геометрия DPI, настройки по умолчанию, рисунок логотипа
tests/           351 модульный тест
scripts/         сборка значков, сайта и кадров, проверки
logo/            logo.svg — исходник, из которого собираются все значки
build/           icon.png, icon.ico и значки трея
site/            страница программы
docs/            документация и кадры интерфейса
```

Архивов с программой в репозитории нет: они лежат в [Releases](../../releases). `node_modules/`,
`out/`, `release/` и `share/*.zip` исключены через `.gitignore`.
